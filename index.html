Illustrative Golay model for an open tubular column with no A term: H = B/u + C·u, with B = 2DM and C ∝ r²/DM. The diffusion coefficients are chosen so that in a 0.25 mm column the optimum velocities match the answer key (about 15, 33 and 52 cm/s). Because B × C does not depend on DM, every gas reaches the same lowest H. A narrower column lowers that minimum (Hmin ∝ r) and moves it to a higher velocity (uopt ∝ 1/r).
